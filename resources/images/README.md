# Rich Menu 圖片規格說明

## 圖片規格
- **尺寸**: 2500 x 843 像素
- **格式**: PNG 或 JPEG
- **檔案大小**: 最大 1MB
- **檔名**: rich-menu.png

## 設計規格
Rich Menu 分成 3 個區域（橫向排列）：

1. **第一格（菜單）**
   - 位置: x=0, y=0
   - 大小: 833 x 843 像素
   - 功能: 顯示主選單

2. **第二格（喝什麼）**
   - 位置: x=833, y=0
   - 大小: 834 x 843 像素
   - 功能: 隨機推薦飲料店

3. **第三格（飲料店）**
   - 位置: x=1667, y=0
   - 大小: 833 x 843 像素
   - 功能: 顯示飲料店列表

## 使用方式
1. 準備符合規格的圖片，命名為 `rich-menu.png`
2. 將圖片放置在此目錄 (`resources/images/`)
3. 執行命令創建 Rich Menu:
   ```bash
   php artisan linebot:richmenu:create
   ```

## 範例圖片模板
您可以使用任何圖片編輯軟體創建符合以上規格的圖片。建議包含：
- 清楚的圖示
- 明確的文字標示（菜單、喝什麼、飲料店）
- 品牌色彩
- 分隔線或視覺區隔
